# hxyfront-62005 管风琴音管调音记录

给管风琴维护人员使用的**音管回装适应工作台**：维修后的音管装回琴室后，先依现场温湿度完成适应，再允许调音，避免“凭感觉马上调音、次日走音”。

## 适应规则

1. 音管装回琴室并在位，从第一次现场温湿度读数开始建立适应过程；
2. 需要相隔**至少 30 分钟**的两次读数，且两次温差**不超过 1.5℃**，状态才变为“可调音”；
3. 适应期间音管**只读、不计完成**，调音表单锁定；
4. 登记**换位取出**或**读数中断**后，适应重新计时（历史读数保留可查，但标记为不计入本轮）；
5. 调音提交保留**音高、音分偏差、异常标记**与备注；调音后再次换位/中断需重新适应；
6. 所有数据只存本机浏览器（localStorage），不上传服务器，可一键清除。

## 文件结构（三个业务文件分开）

- `src/acclimatization.ts` — 适应状态机：读数、30 分钟间隔、1.5℃ 温差、换位/中断重置、调音门控（纯逻辑）
- `src/storage.ts` — 记录存储：localStorage 读写、数据校验、首次示例数据、清除
- `src/Workbench.tsx` — 页面组件：音管列表、状态筛选、读数时间线、调音表单、适应提示
- `src/App.tsx` — 仅挂载工作台
